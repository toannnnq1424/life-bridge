# Model Policy

Codex App uses the session's configured OpenAI model. LifeBridge does not use
9Router or external model-routing infrastructure.

- Architecture, security, review, migrations, and integration use the most
  reliable available reasoning configuration.
- Routine documentation or bounded boilerplate may use a faster supported model
  only when output is reviewed.
- A model change does not alter acceptance criteria or authorization.
- No task may claim cost/token savings without measured comparable evidence.
